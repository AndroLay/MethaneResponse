# English guide to preserved evaluation packets

All maintained repository documentation uses English. Some original evaluation
packets contain Indonesian instructions, answers or reviewer preparation material.
Those originals are retained verbatim because their bytes are bound to frozen
protocols and checksums. This guide provides English explanations; it does not
replace an original protocol, translate an agent answer into a different answer,
change a score or create a new study.

The original documentation before the English conversion is also available at
Git revision `9d38ad2`. Historical manifests must be checked against their recorded
revision, not rewritten to accept a later editorial translation.

## Frozen r12: report the original result

The [frozen r12 report](agent-practical-usefulness-2026-10-21-r12/findings.md)
records 48 sealed attempts: eleven completed, thirty-four abstained, three failed.
Task completion under its scorer is **0/48**; decision accuracy **8.33%**;
actionability **74.3%**. All twelve deterministic gates passed. Zero false-supported
results were recorded for fifteen assessed cases and zero critical overclaims for
forty-five available assessments. No composite score was available.

The retrospective, nonexclusive recovery classification is 22 scorer false
negatives, three agent/tool failures, zero application defects proven from r12,
one genuine task failure and 38 protocol limitations. These counts overlap and
must not be added into 48 exclusive categories. Four outputs satisfying a separate
adapter are not four successful new episodes. Preserve missing fields, incorrect
source IDs, wrong allocations, missing reason codes and absent trusted digests as
failures where the task requires them.

## Reviewer-packet instructions in English

The P4 packets request documentary criticism, not endorsement or certification of
equipment repairs. Allow approximately 60–75 minutes or asynchronous review.

1. Privately establish relevant expertise, assessable scope, conflicts and consent.
2. Read the method brief, source register and twelve cases before seeing the
   implementation's outputs. Record initial conclusions, rationale, locators,
   uncertainty, omitted cases and requested evidence. Inadequate labels and unable
   to assess are valid responses.
3. Then inspect the separate baseline comparison and record substantive differences.
   This sequence is not a blinded accuracy study.
4. Identify each finding's case/version, severity, consequence, supporting locator,
   wording at risk, required change/evidence and expertise limits.
5. Apply relevant fixes, preserve original answers privately and ask for material
   findings to be reassessed. Do not redefine success to erase disagreement.
6. Obtain separate approval for public summary, quotations, name and affiliation.
   Blank permission means not granted. Keep identity, contact details, signatures,
   qualification evidence and restricted documents out of public source.

The case set covers: KAZ detection, event-specific KAZ notification, broader KAZ
mitigation scope, Canadian post-action evidence, Libyan sparse follow-up and
Argentinian report/rights limitations. DEMO cases exercise notification matching,
contrary records, conflicting references, period boundaries, complete-looking
metadata without physical validation and missing follow-up measurements. Refer
to the unchanged structured inputs for exact IDs, timestamps and numeric values;
this guide does not silently translate or modify frozen input fields.

Flux uses kg/h. Publisher standard deviation is a separate field, not a confidence
interval or app-model confidence. Source-level notification/feedback flags do not
establish a recipient or event timestamp. Link-only publisher metadata does not
license report reproduction or authenticate report content. The internal category
`mitigation_confirmed` names a claim under review, not a verified physical status.

The original packet HTML remains an archival view in its original language. Use
this English reading guide and the maintained [method/data guide](../product/data-and-claims.md)
and [review checklist](../testing/p4-review-checklist.md) for English explanations.

Feedback is not repair. Missing later observations are not zero methane. A hash or
receipt establishes integrity/chronology under stated trust assumptions, not
physical truth. Agent simulations are not human research. No measured productivity,
facility repair or emissions-reduction outcome is established by these packets.
