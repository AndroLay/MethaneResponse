## Documentation and historical binding

The documentation guide was reorganized on 17 October 2026 after the trust/transparency increment. Existing evidence files, screenshots, manifests and checksums retain their original bytes. Hashes that bind an earlier version of a guide are historical source bindings, not a claim that the rewritten guide was tested in that run. Start at the [documentation index](../README.md) for active guidance and [current status](../release/current-implementation-status.md) for the latest recorded implementation checks.

## Read evidence correctly

- Treat the snapshot ID and archive hash in each record as part of its result.
- Treat an AI browser run against a deterministic mock provider as workflow coverage, not as an AI quality score.
- Treat a disposable PostGIS test as migration/integration coverage, not a cloud backup or multi-region test.
- Treat a local report digest or blockchain receipt as evidence of bundle integrity and chronology, not proof that a leak was repaired.
- For current source behavior, start with the root [README](../../README.md); for historical data provenance, use [`data/real/README.md`](../../data/real/README.md).

- [Persiapan operasi Sepolia P2](sepolia-preparation-2026-10-17/README.md): target/config privat dan audit operasional siap; ketiga operasi disetujui, belum ada receipt publik. Setelah kendala faucet, [jalur testing lokal](p2-local-testing-2026-10-17/README.md) dijalankan ulang tanpa memerlukan funding.
