## Manual publisher archive versus the application

The manual comparator here uses a local MARS metadata packet from the same snapshot. This is not a live test of the official portal. The agent walkthrough checked functionality; it did not measure user benefit or human-user time.

| Task | Packet/manual | MethaneResponse | Demonstrable value / limit |
|---|---|---|---|
| Trace a source/observations | Read fields/IDs/dates/flux/uncertainty and provenance | Source detail, observation table, and snapshot in one flow | Reducing navigation across document structures is a benefit hypothesis; human time savings have not been measured |
| Prioritize review | Build a rationale from count/date/flux/uncertainty | Heuristics and an input/rationale panel | Score can be inspected; it is not an emissions probability or authoritative operational decision |
| Assess response/mitigation | Interpret whether the packet is sufficient; request missing evidence contents | Scope/event/recipient and coverage checklist; separate human assessment; optional Document AI | Metadata alone cannot establish the truth of the full proposition. The app does not add physical evidence missing from the packet |
| Handoff and revision | Separate notes/files; process/authorization depends on the team | Shared casework, next action, CAS/history, audit revision, and publication consent | Local capability has P1/P3 evidence; this is not real adoption or a multi-instance service |
| Correct a publication | Mechanism depends on publishing channel | Current/superseded/withdrawn status, lineage, history | Server publication metadata is unsigned; downloaded old copies cannot be recalled |
| Check an export | Use a suitable digest tool/algorithm | Export and browser/CLI verifier | Tampering can be checked; integrity is not source authenticity or physical truth |

## Closest public comparators

Sources: [16 October research](../../research/competitive-landscape-2026-10-16.md). **Not rechecked in the 18 October increment.** Links, repository/demo state, and maker claims may change. No competitor product was run in this increment; this table is not a ranking of all submissions.

| Comparator | Maker claim recorded on 16 October | Evidence inspected in the earlier research | Lesson for MethaneResponse scope |
|---|---|---|---|
| PLUME | Methane investigation → escrow → repair verification → settlement | Public page and repository structure/README read; preview and demo actions described as simulated. Not executed | Broader action/funding flow; our product focuses on tracing evidence sufficiency, handoff, and correction |
| Kanopy | Forest/carbon quantification, uncertainty, and registration | Public description and verifier link; transaction/measurement not reproduced | Show number provenance/uncertainty before relying on a hash |
| CarbonTwin | Registry overlap, release steward/adjudication/versioning/anchor | Public page and repository link; new-release coverage not audited/tested | Revision + AI + blockchain is not a differentiator by itself |
| Mizan | Cited document extraction, counting, and human review/Hedera | Public page and maker-reported evaluation; not an independent audit or our execution | AI value needs a benchmark on exact inputs; text-matching citations do not authenticate a document |

**Differentiator hypothesis:** one historical methane-response investigation trail from source/date → scope → evidence sufficiency → owner/next action → revision → publication correction → verifier. That flow can be demonstrated locally. Usability versus manual work and AI quality versus rules still require appropriate study results.

Current safe conclusion: “The agent successfully ran part of the local workflow and found the evidence limits displayed by the application.” Do not turn this into a claim of faster users, more accurate AI, emissions reduction, or competition ranking.
