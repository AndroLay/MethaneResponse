# P5 and P6 Execution with Agents

**Direction:** the user asked to complete P5/P6 through agents. The six-package plan remains the research reference; agent results have separate status and do not satisfy the human/provider gates.

## Work that must actually be completed

1. Freeze tasks, the two P5 cases, the app source archive, assignments, and scoring rules before sessions. Run six agent sessions using the manual/app conditions; record answers, actual time if measurable, assistance, failures, and exit beliefs. If the same agent runs multiple sessions, do not count them as independent participants.
2. Freeze P6 on a source subset separate from the four pilot/demo cases. Write propositions about **historical record contents**, not whether physical repairs occurred; retain dataset attribution and licensing. Have two agents assess without seeing comparison labels or each other's assessments.
3. Run the rules and agent assessments on the same documents/claims. Check citations with the app verifier. Calculate agreement, three-class results, false support, abstention, source-cluster interval, and paired differences. Report zero/negative results; do not tune the test set to produce a win.
4. Resolve material findings within this scope, run relevant tests and review. Freeze results, checksums, and active status. Do not enable the app provider or describe agents as experts/human users.

## Decisions before results

- P5: LBY_S_143 and CAN_S_002; four tasks follow the earlier task package. The manual condition receives the same metadata and baseline export, so T4 compares **verification**, not MARS's native ability to create an export. Agent time includes tooling and is not a measure of time saved for people.
- Schedule six sessions across four workflow/case combinations; an agent may run three sessions in sequence. Report learning effects and the actual number of agents. Do not fabricate human confidence.
- P6: 12 test sources, six claims per source (72 claims); two record-supported, two record-contradicted, and two insufficient. Documents are summarized from the local snapshot licensed under CC BY-NC-SA 4.0; report bodies are not included. Claim templates are authored challenges, not publisher statements discovered in the real world.
- The comparison rules are a deterministic record parser frozen before assessment; document-content semantics match those used for agents. Report app coverage baseline separately because it does not read propositions.
- Agent labels/predictions are not human gold. Diagnostic results always remain `humanResearchGatePassed: false`, `providerBenchmarkCompleted: false`, `activationEligible: false`.
- Agent completion requires all sessions/claims to be recorded and results/limits to be inspectable; it does not require AI to beat the rules. The original research still requires people, an authorized corpus, and a suitable provider.

## Final results

- [x] P5: two agents ran six repeated sessions, 48/48 tasks; answers, timing, assistance, and exit beliefs were saved. Scoring was 40 correct/8 partly correct, with every deviation retained. The median of 15 eligible pairs showed the app was slower in agent wall time; no human benefit is claimed.
- [x] P6: 72 test claims/12 sources, two agent contexts, identical rules and inputs; predictions, grounding, and metrics are complete. Each agent scored 71/72 versus rules at 72/72, with the same errors; the decision does not confer activation eligibility.
- [x] CLI findings were fixed after sessions; 25 pilot files were replayed in 50 checks with expected results. Bindings for 216 assessments were recomputed. Tests/review were performed; `check:all` passed 708 tests plus typecheck/build/bundle.
- [x] The [results package](../evidence/p5-p6-agent-completion-2026-10-18/README.md), manifest/checksum, and active docs were aligned; historical artifacts were retained.

**The agent scope is complete.** The human/provider research in the six-package plan remains incomplete. Human gold was not replaced with agent output, and no claim is made that AI outperformed the rules.
