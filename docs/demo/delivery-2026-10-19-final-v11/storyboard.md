## Transitions and overlaps

- Presentation → app: the same first source frame appears in a smaller preview,
  then its shared window expands to full size over 1.1 seconds. Cursor becomes
  visible after entry. No fake overlay is substituted for the UI.
- App → presentation: the exact last source frame contracts for 1.15 seconds;
  pointer fades over 450 ms and the presentation palette emerges gradually.
- Significant figures and diagram rows use generated word timestamps, with a
  120 ms anticipation and a short eased reveal. Titles introduce context; they
  do not claim that a later UI action has already happened.
- During typing, camera centers move between the three real input regions using
  continuous fractional transforms. Zoom is capped and returns to a still frame
  before each edit boundary. Actual app scrolls are not chased by another pan.
- The instrumental ducks under narration; short action/reading pauses remain.
  All final technical claims refer to the new export, not the old v10 audio.
