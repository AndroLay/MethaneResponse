## Production decision

The shared technique is **explanation → actual interaction → result/limits**, with a visible change in visual mode at each step. The new film uses authored motion graphics for context, MARS’s role, the discrete observation plot, and the timing ambiguity; actual MethaneResponse footage proves source selection, rules assessment, follow-up note, and report verification. The result is not a full-screen screen recording with captions added afterward.

The reference samples are not production assets and are not included in the final package. No statement about their audio, exact cut timing, or full-film quality is made.
