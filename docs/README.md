# Dokumentasi MethaneResponse

Dokumentasi operasional starter dan catatan riset hackathon disatukan di folder ini. Dokumen pada `research/` menyimpan riwayat riset dan perbandingan kandidat; status implementasi terkini tetap mengikuti README utama serta catatan delivery.

## Dokumentasi proyek

- [Architecture](architecture.md) — batas sistem, alur bukti, dan status prototipe.

- [Prospective recurrence evaluation](prospective-recurrence.md) — ledger prediksi source MARS yang dibekukan, cara evaluasi snapshot masa depan, dan batas interpretasinya.
- [Research-to-product evidence](research/methane-response-evidence-and-evaluation-2026-10-13.md) — riset primer UNEP, validasi satelit controlled-release, IEA, dan ALCE; keputusan visualisasi, AI, prediksi, serta bukti penjurian (diperbarui 14 Oktober 2026).
- [Delivery notes](delivery-notes.md) — apa yang dilaporkan pembuat ZIP dan apa yang sudah diperiksa.
- [Deployment](deployment.md) — target deployment dan konfigurasi yang belum diterapkan.
- [Next steps](next-steps.md) — urutan pekerjaan berikutnya.
- [Master execution plan](MASTER_EXECUTION_PLAN_2026-10-14.md) — rencana eksekusi rinci, acceptance criteria, dependency, estimasi, gate dan fallback sampai submission dan kesiapan berbukti.
- [Execution checkpoint](EXECUTION_CHECKPOINT_2026-10-14.md) — perubahan yang sudah diterapkan, gerbang verifikasi terbaru, bukti browser lokal dan prasyarat yang belum tersedia.
- [Local quality gate evidence](evidence/local-quality-gate-2026-10-14.md) — command, hasil full suite PostGIS lokal, hash baseline, browser smoke, dan batas verifikasi.
- [Real map implementation](REAL_MAP_IMPLEMENTATION.md) — impor dataset MARS lokal, peta interaktif, lisensi, dan batas interpretasi.
- [Earth rendering 3D](EARTH_RENDERING_3D.md) — terrain DEM, atmosfer MapLibre, profil kualitas adaptif, dan layer konteks NASA.
- [Landing page](LANDING_PAGE.md) — navigasi dan konten halaman publik prototype.
- [UI implementation](UI_IMPLEMENTATION.md) — status dashboard, alur browser, dan hasil verifikasi lokal.
- [Premium UI redesign](PREMIUM_UI_REDESIGN_2026-10-13.md) — perubahan tampilan, workspace Cases, rujukan mockup, serta bukti dan batas pemeriksaan browser.
- [User workflow and benefits](user-workflow.md) — cara mencoba enam manfaat produk melalui rute workspace yang berfungsi beserta batas konfigurasi AI dan blockchain.
- [Anchor recovery and grounded evidence](ANCHOR_RECOVERY_AND_AI_GROUNDING_2026-10-13.md) — migrasi reservasi transaksi, pemulihan receipt, token reviewer berscope, impor PDF/TXT, dan evaluasi AI independen.
- [Judge evidence matrix](judge-evidence-matrix-2026-10-13.md) — bukti terukur untuk empat kriteria yang ditargetkan, hasil gerbang lokal terbaru, dan prasyarat eksternal.
