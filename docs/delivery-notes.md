## Delivered locally

- The API and dashboard use a traceable, hash-pinned UNEP MARS casebook with three real sources and six linked plume observations. Synthetic fixtures remain separate and explicitly marked.
- Claim categories keep detections, source-level notification metadata, feedback, and mitigation distinct. Real mitigation claims abstain because linked report contents have not been included or reviewed.
- The deterministic baseline emits cited evidence and provenance. Audit bundle revisions persist to an atomic local file or configured PostgreSQL/PostGIS. Production startup requires `DATABASE_URL`.
- The offline CLI independently recomputes canonical SHA-256 for exported v2/v3 bundles and rejects changed report content or duplicated result fields. With Sepolia read settings, it checks the transaction receipt/event and current registry version directly. The Solidity registry and receipt matching are locally tested; there is no Sepolia contract or transaction configured.
- The dashboard supports case/source review, historical map import, region and sector filters, a synthetic demo, audit citations, JSON export, and receipt status. A failed map chunk, unavailable WebGL, or actual globe context failure leaves the rest of the dashboard usable. Software WebGL can render the globe at reduced quality.
- The hash-bound intelligence snapshot analyzes all 4,211 sources and 23,785 explicitly linked observations in the pinned full MARS browser dataset. Its separate robust outlier screen records stated thresholds, per-observation uncertainty, traceable candidate details, and explicit insufficient-data states; candidates are statistical follow-up signals, not validated leak detections.
- The map opens on a historical reported-flux overlay: 29,256 positive, coordinate-valid archive rows are colored by reported kg/h; low-power rendering summarizes them with median values in approximately 1° cells. `LIVE FEED OFF`, dates, units, and layer-specific limitations remain visible. MapLibre initialization waits until the map enters a 96 px viewport margin; browsers without `IntersectionObserver` load immediately. The heat colors are not continuous concentration, live weather, or confirmed plume boundaries; investigation priority is separately labeled heuristic rather than forecast probability.
- The map's keyless globe view now opens on a centered MARS casebook overview; fullscreen camera sizing keeps the sphere prominent as the panel grows. At a 1280×800 browser viewport, the 1219×679 fullscreen map rendered the globe at zoom 1.7. Hardware Chromium rendered Esri satellite imagery, the sphere globe, and adjustable grayscale without browser console errors. This is a textured globe, not 3D terrain or photogrammetric buildings.
- Root docs, data rights notices, CI configuration, deployment guidance, and a reproducible local quality script are present.

**Evidence-input update (2026-10-14):** interactive document assessments now require an explicit per-document rights declaration (`owned` or `explicit_permission`) in addition to provider opt-in. The declaration is included in the hashed report and labeled self-reported; it does not establish copyright ownership or permission independently.

### 2026-10-13 follow-up: report binding and approval guard

- Audit JSON exports now checksum the complete exported wrapper. The browser verifies loaded snapshot bytes against a manifest that records both gzip and decoded content hashes, then compares the loaded file hash to the audit's pinned input hash. When the current snapshot differs, export omits its observations. The browser verifier rejects altered wrapper values and distinguishes this checksum from audit bundle and chain verification.
- Private audit list/detail access is reviewer-only. The assessor token can submit an assessment but cannot retrieve private history or details.
- Review approval now requires the reviewer to attest to inspecting the original source and at least one exact quotation already validated against the submitted excerpt. This is recorded in the hashed review revision; rejected and “more evidence” decisions remain available without that attestation.
- Local tests cover wrapper tampering, altered input bytes with matching snapshot/archive IDs, mismatched dataset omission, assessor-token read denial, and approval guards. The full local mock UAT is complete at revision 8. The external model, evidence-source authenticity, deployed auth, persistent remote database, and Sepolia remain unverified.
